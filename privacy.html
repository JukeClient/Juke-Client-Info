Privacy

This page explains what the Juke Client launcher and this website store locally, which services they contact, and how to remove that data. It describes the current development build; final terms will be published with the first public release.

At a glance

Summary of data handling
AreaWhat happens
On your computerSettings, profiles, game files, worlds, logs, an optional custom skin, your local friends list and one theme preference are stored locally.
Over the networkOnly requests needed for Microsoft sign-in, Mojang version metadata and game downloads, Java runtime downloads, loader metadata and files (Fabric, Forge, NeoForge and Quilt), mod metadata and downloads, release news and update checks.
AnalyticsNone. No analytics, telemetry, crash upload or advertising trackers are used.
Your passwordNever collected. Microsoft sign-in happens in the system browser.

The update request exposes your IP address to GitHub and includes the launcher version and target platform. It contains no identifier of our own, no profile, world or game data. If you accept an update, the installer is verified with a Juke Client minisign key before installation.

What is not sent

  • No crash reports, logs, skins, worlds, profiles or local friends data are uploaded automatically.
  • No Microsoft passwords are collected. The authorization code arrives only on a temporary loopback callback; the juke-client:// return link carries no code or token.
  • We attach no identifier of our own to update checks or website visits. Providers and hosting services may still see standard connection data such as your IP address.

Age

Minecraft has a young audience, but Juke Client and this website are not intended for children. The age at which a person can consent to online services varies by country, so check the rules where you live. This site collects no personal data, and Microsoft handles account sign-in under its own terms. We do not ask children to provide personal data to this website or to the project contact address. Parents or guardians with questions about contact with the project can use the address below; please do not include personal data in the message.

Removing data

  1. Use the operating system's uninstall control to remove the launcher application.
  2. Open the launcher's profile manager and delete any profile you no longer need. Deleting a profile moves its game directory to the operating-system trash.
  3. Delete the launcher's application data folder if you want to remove remaining settings, logs, your custom skin and local friends data. Keep any worlds you want to preserve first.
  4. Remove saved credentials from Windows Credential Manager (or your platform's keychain) if you want to discard the sign-in token and optional CurseForge key.
  5. To remove the site's theme choice, clear site data for this page in your browser.
